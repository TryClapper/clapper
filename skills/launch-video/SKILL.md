# Launch video (Clapper Open Source)

This plugin's code is open source. The instructions for making the video are run by Clapper and fetched
when you need them, so they are always the current ones.

Before anything else, run:

```
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/clapper_get.py" skill
```

and follow what it prints as this skill's instructions, exactly and in full, including picking up a video
that stopped part way. Wherever they name `clapper_get.py`, run this same script.

If it prints "Clapper needs an internet connection to make a video.", tell the person exactly that, in
those words, and stop.
